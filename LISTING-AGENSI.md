## 3. Pełny opis listingu

```
Built by one ADHD adult, for himself, over months of daily use — not designed on a whiteboard.

This skill turns any SKILL.md-capable agent (Claude Code, Cursor, Codex, Hermes, and any other tool that loads skills) into an assistant that works WITH an ADHD brain instead of against it. It encodes eight behavioral rules that fix the two things that make AI assistants exhausting when you have ADHD: you never know what it's doing, and it keeps asking you questions you don't have the energy to answer.

WHAT IT CHANGES
- Nothing runs without you knowing. Background work — a build, a subagent, a long command — is announced in one line before it starts. No discovering afterward that tokens were spent on something you didn't ask about.
- "Just handle it" actually works. Vague input gets acted on, not interrogated. It asks back only when the decision genuinely can't be guessed — one precise question, not a checklist.
- It picks up where you left off, unprompted. Open a session and get "here's where we were", not "how can I help today".
- Memory is captured the instant something is said — not at some tidy finish line that may never come.
- Messy input in, organized output out. A brain dump comes back as: what it means, why it matters, what to do next. Never a wall of pasted text or a link cemetery.
- No sycophancy, no motivational padding. If you're wrong it says so and moves on. (Research links LLM sycophancy to eroded trust and dependency — for a brain that struggles to tell "felt reassured" apart from "actually handled", that's a bad trade.)
- Proof over promise. "Done" always ships with something checkable: the file path, the diff, the command output.
- Loop check. On the 3rd iteration of the same side-quest, it stops and names the original goal — one line, then asks if continuing still serves it.

INSTALL
Unzip into ~/.claude/skills/handle-with-adhd/ (or your agent's skills folder) and invoke handle-with-adhd. No config, no accounts, no dependencies. MIT licensed.

HONEST LIMITS
Not a clinical tool, not a substitute for anything you and a doctor have worked out, and not tested on anyone but its author. It might do nothing for you — ADHD doesn't work the same way twice. Published because the thing that helped me doesn't seem to exist anywhere else yet.
```
